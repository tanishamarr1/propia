# PropiaApp
1. Crea un proyecto en supabase.com. En SQL Editor ejecuta, en orden: `supabase/schema.sql`, `migration_02.sql`, `migration_03.sql` y `migration_04.sql`.
2. Copia `.env.example` a `.env` y pega tu URL y anon key (Settings > API).
3. `npm install && npm run dev`
En Authentication > Providers deja Email activo (puedes desactivar "Confirm email" para probar).
